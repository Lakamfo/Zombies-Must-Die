# Zombies Must Die

`Zombies Must Die` is a Godot-based game built as a zombie shooter. The project supports running locally from the editor, exporting game builds, and includes a backend server component for handling game requests.

## About the Project

- Name: `Zombies Must Die`
- Description: classic "COD : Zombies" style shooter, open source in future
